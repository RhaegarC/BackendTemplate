# IM-14 — `EntityId` is null for database-generated keys on insert

- **Priority:** 🟡 Low
- **Area:** Data
- **Status:** Done
- **Index:** [improve.md](../improve.md)

## Problem

`GetPrimaryKeyValue` in `src/content/Tmp.Repository/AuditSaveChangesInterceptor.cs` reads
`CurrentValue`, which is unset for an `Added` entity whose key is generated by the
database.

The audit row therefore records a null `EntityId` for exactly the inserts you would most
want to trace.

## Direction

Capture the key after the save, or require application-assigned keys (which would also
resolve [IM-12](IM-12-KeyStrategy.md)).
